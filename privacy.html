プライバシーポリシー

calendar-recipe（以下「本アプリ」）は、開発者本人が自身の予定管理のために開発・運用する個人用のツールです。本ポリシーは、本アプリが Google API を通じて取得する情報の取り扱いについて説明します。

1. 取得する情報

本アプリは、利用者本人の OAuth 同意に基づき、Google Calendar API（スコープ: https://www.googleapis.com/auth/calendar）を使用して、利用者本人の Google カレンダーに保存された予定データ（予定のタイトル、開始・終了日時、場所、説明、通知設定など）を取得します。それ以外の Google アカウント情報（メール本文、連絡先、ファイルなど）は取得しません。

2. 利用目的

取得した予定データは、利用者本人による予定の登録・変更・キャンセル処理のためにのみ使用します。広告配信、マーケティング、プロファイリング、機械学習モデルの訓練などの目的には一切使用しません。

3. 情報の保存場所と保存期間

本アプリは利用者本人のデバイス（PC および自宅 NAS）上でのみ動作し、開発者が管理する外部サーバーは存在しません。Google API の認証情報（credentials.json / token.json）は利用者本人のデバイス内にのみ保存されます。予定データは処理のために一時的に読み取られるものであり、本アプリが独自のデータベースに蓄積することはありません。

4. 第三者への提供・共有

取得した情報を、第三者へ販売、提供、共有することはありません。法令に基づく開示請求がある場合を除き、本人の同意なく情報を開示することもありません。

5. Google API Services User Data Policy への準拠

本アプリによる Google API から取得した情報の使用および他のアプリへの転送は、Limited Use の要件を含む Google API Services User Data Policy を遵守します。

calendar-recipe's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. アクセス許可の取り消しとデータの削除

利用者は、Google アカウントの「セキュリティ」→「サードパーティ製のアプリとサービス」の設定から、本アプリへのアクセス許可をいつでも取り消すことができます。また、本人のデバイス内の token.json を削除することで、本アプリからのアクセスを即時に無効化できます。

7. セキュリティ

認証情報は本人のデバイス内でのみ保管し、外部に送信しません。認証情報の保管場所には本人のアカウントのみがアクセスできるよう設定します。

8. 本ポリシーの変更

本ポリシーを変更した場合は、本ページ上で告知します。
